## Newsletter sign-ups (Google Sheets)

The footer's Corporate Briefings form posts to a server action
(`app/_actions/newsletter.ts`), which forwards the email to a Google Apps
Script web app that appends it to a Google Sheet.

1. Follow the setup steps at the top of `docs/newsletter-apps-script.gs`.
2. Set these environment variables (see `.env.example`), locally in
   `.env.local` and in your hosting provider:
   - `NEWSLETTER_SCRIPT_URL`: the web app's `/exec` URL
   - `NEWSLETTER_SCRIPT_SECRET`: the same value as the script's
     `SHARED_SECRET` property

Until both are set, the form shows a polite "couldn't add you" message.
